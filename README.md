# Barbearia Altas Horas

Site institucional da **Barbearia Altas Horas**, localizada em Engenhoca, Niterói/RJ.

## Tecnologias

- HTML5 + CSS3 + JavaScript puro
- Sem frameworks ou dependências externas (exceto Google Fonts)
- Hospedagem: GitHub Pages

## Estrutura

```
├── index.html
├── RESEARCH.md          # Pesquisa e dados confirmados
├── ASSETS-SOURCES.md    # Fontes de imagens e assets
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── favicon.svg
```

## Desenvolvimento

Abra `index.html` diretamente no navegador ou sirva a pasta localmente:

```bash
npx serve .
```
